# 데이터 전처리 및 ADF 검정

## 변환

- 유가: `100 * (ln(oil_t) - ln(oil_{t-1}))`
- 환율: `100 * (ln(fx_t) - ln(fx_{t-1}))`
- CPI: `100 * (ln(cpi_t) - ln(cpi_{t-1}))`
- 기대인플레이션: 수준과 전월 대비 차분을 모두 검정

- 전처리 후 표본: 2010-02-01 ~ 2026-02-01
- 전처리 후 행 개수: 193개

## 기대인플레이션 처리 결정

메인 분석에서는 기대인플레이션율 수준(level, %)을 사용합니다.

이유: 연구 질문이 '유가 충격이 기대인플레이션율을 몇 %p 움직이는가'이므로 수준 변수의 해석이 가장 직접적입니다. ADF 검정에서는 기대인플레이션 수준의 p-value가 0.106으로 5% 기준 단위근 가능성이 있으므로, 마지막 강건성 분석에서 전월 대비 차분(Δ기대인플레이션)을 사용한 대체 모형을 함께 보고합니다.

- 메인 VAR 투입용 기대인플레이션 열: `expected_inflation_level`
- 강건성 VAR 투입용 기대인플레이션 열: `d_expected_inflation`
- 러-우 전쟁 더미: `ru_war_dummy`, 2022-02부터 2023-06까지 1, 그 외 0
- 전체 전처리 파일의 `expected_inflation_for_var`는 메인 분석 기준에 맞춰 수준 변수로 반영했습니다.

## 저장 파일

- 전체 전처리 파일: `data/processed/svar_preprocessed_201002_202602.csv`
- 메인 분석용 파일: `data/processed/svar_main_level_201002_202602.csv`
- 강건성 분석용 파일: `data/processed/svar_robust_diffexp_201002_202602.csv`

강건성 분석에서는 같은 종속변수 구성에서 `ru_war_dummy`를 외생변수로 포함한 VAR과 포함하지 않은 VAR을 비교합니다.
